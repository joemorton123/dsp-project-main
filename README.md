# Godot RL Agents

This repository contains the Godot 4 asset/plugin for the Godot RL Agents library. You can find out more about the library on its GitHub page here: https://github.com/edbeeching/godot_rl_agents.

Godot RL Agents is a fully open source package that allows video game creators, AI researchers, and hobbyists to learn complex behaviors for non-player characters or agents.

It provides the following functionality:
- An interface between games created in the Godot Engine and machine learning algorithms running in Python
- Wrappers for three RL frameworks: Stable-Baselines3, Sample Factory, and Ray RLlib
- Support for memory-based agents, with LSTM or attention-based interfaces
- Support for 2D and 3D games
- A suite of AI sensors to augment an agent's ability to observe the game world
- MIT-licensed and free to use

You can find out more about Godot RL Agents in the AAAI-2022 Workshop paper: https://arxiv.org/abs/2112.03636.
